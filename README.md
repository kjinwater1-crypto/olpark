# 실시간 주차 기록

올림픽공원 홈페이지 주차 안내 페이지 https://www.ksponco.or.kr/online/main/parking.do 에 표시되는 실시간 주차 대수와
시간대별 예상 이용률을 GitHub Actions로 20분마다 기록합니다. 2026년 11월 15일에 공개해 둔 올팍 주차날씨 예보와
실제 값을 비교하는 데 씁니다. 기록 스크립트는 main 브랜치의 `live/record.py`, 실행 설정은 `.github/workflows/live.yml`입니다.

- `rt_log.csv`: 기록 시각(한국 시간), 실시간 주차 대수, 페이지의 '가능' 대수 표시
- `official_expect.csv`: 페이지의 시간대별 예상 이용률. 값이 바뀔 때만 기록합니다.
- `errors.csv`: 페이지를 읽지 못한 때의 기록

실시간 주차 대수에는 출차 기록이 없는 장기 주차 차량이 포함되어 새벽에도 1,000대 안팎이 표시됩니다.
그래서 비교할 때는 그날 새벽 값을 뺀 증가분을 씁니다.
